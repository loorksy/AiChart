# جسر MT5 الذاتي — بديل MetaApi (تجريبي على Linux)

> **تنبيه (2026):** على **Linux + Wine** يفشل `mt5.initialize()` بـ `IPC timeout (-10005)`.
> **الحل الموصى به:** `FOREX_BACKEND=ea` + MetaTrader على **VPS Windows** — راجع
> [`docs/EA_WINDOWS_VPS.md`](../../docs/EA_WINDOWS_VPS.md). استخدم هذا الجسر فقط على
> **Windows VM** حيث يعمل IPC أصلياً.

MetaTrader 5 حقيقي يعمل داخل حاوية Docker على سيرفرك (تحت Wine) مع واجهة
REST صغيرة. لا خدمات خارجية، لا اشتراكات — الاتصال الخارجي الوحيد هو اتصال
MT5 بسيرفر وسيطك (نفس اتصال أي منصة MT5 عادية).

تجربة الاستخدام بعد التشغيل: من إعدادات المنصة تدخل ثلاثة حقول
(السيرفر، رقم الحساب، كلمة المرور) — مثل MetaApi تماماً.

## المتطلبات

- ذاكرة حرة 1.5 إلى 2 جيجابايت على الخادم (تحقق بـ `free -h`).
- حساب MetaTrader **5** (الحاوية لا تدعم حسابات MT4 — لذلك استخدم جسر EA).
- البناء الأول يستغرق ~10 دقائق ويحمّل ~1 جيجابايت (Wine + MT5 + Python).

## التشغيل

```bash
# 1) التوكن المشترك بين المنصة والحاوية
openssl rand -hex 24    # ضع الناتج في web/.env كـ MT5_BRIDGE_TOKEN

# 2) في web/.env
MT5_BRIDGE_URL=http://localhost:18812    # (أو http://mt5:18812 إن كانت web في compose)
MT5_BRIDGE_TOKEN=<الناتج أعلاه>

# 3) بناء وتشغيل الحاوية وحدها (تعمل مع web على pm2 أيضاً)
cd infra
MT5_BRIDGE_TOKEN=<الناتج> docker compose up -d --build mt5
docker compose logs -f mt5      # انتظر: [shim] listening on :18812

# 4) أعد تشغيل web ليلتقط المتغيرات
pm2 restart aichart-web
```

بمجرد ضبط `MT5_BRIDGE_URL` تتحول خلفية الفوركس تلقائياً إلى الحاوية،
ويظهر نموذج الحقول الثلاثة في الإعدادات → الربط والتكامل → MetaTrader.

## كيف يعمل

1. تدخل بياناتك من لوحة التحكم → المنصة ترسلها للحاوية (`POST /connect`).
2. الحاوية تشغّل terminal64.exe وتسجّل الدخول لحساب وسيطك مباشرة.
3. تنفيذ الصفقات: وكيل Claude MCP → Bridge API → Risk Guard → الحاوية → الوسيط.
4. الأسعار والشموع والشارتات تُقرأ من الحاوية مباشرة (بلا EA وبلا سحابة).
5. البيانات تُحفظ داخل volume `mt5-data` لإعادة الاتصال تلقائياً بعد إعادة التشغيل.

## الأمان

- المنفذ 18812 مربوط على 127.0.0.1 فقط — لا تكشفه للإنترنت أبداً.
- كل النداءات تتطلب ترويسة `X-Bridge-Token` المطابقة لـ `MT5_BRIDGE_TOKEN`.
- بيانات الدخول تُخزن مشفّرة في قاعدة بيانات المنصة، وداخل volume الحاوية
  لإعادة الاتصال — كلاهما على سيرفرك أنت.

## استكشاف الأخطاء

| العرض | السبب/الحل |
|---|---|
| `not connected — POST /connect first` | أعد الربط من إعدادات المنصة |
| فشل تسجيل الدخول | تحقق من اسم السيرفر حرفياً كما في تطبيق MT5 (مثل `Exness-MT5Real8`) |
| `symbol not found` | بعض الوسطاء يضيفون لاحقة للرموز (`EURUSDm`) — استخدم الرمز كما يظهر في Market Watch |
| الحاوية تستهلك ذاكرة كبيرة | طبيعي (~1.5GB) — هذا MT5 كامل تحت Wine |
| `IPC timeout` / `-10005` | Wine على Linux — انتقل إلى جسر EA (Windows) |
